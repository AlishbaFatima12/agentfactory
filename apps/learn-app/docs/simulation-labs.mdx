# Simulation Labs

Interactive, IDE-style environments where you explore real AI platform projects — without installing anything.

**How to use:**
1. **Browse the file tree** (left panel) — click folders to expand and files to view their source
2. **Read annotated code** (center panel) — highlighted lines show inline annotations explaining what the code does and why
3. **Try commands** (right terminal panel) — type commands like `/help` or `/agents` to explore concepts interactively
4. **Start from the welcome page** — click any concept card to jump straight to the relevant file
