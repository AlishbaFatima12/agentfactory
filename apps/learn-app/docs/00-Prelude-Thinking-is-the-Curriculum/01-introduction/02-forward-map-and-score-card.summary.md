### Core Concept
The ten chapters form a dependency graph, not independent workshops. Each chapter produces a named skill or tool that later chapters explicitly build upon, and the Thinking Score Card tracks growth across five dimensions over all 40 exercises.

### Key Mental Models
- **Skill Dependency Chain**: Each chapter's output becomes a named input to later chapters (e.g., Prediction Lock from Ch 1 is reused in Ch 2, 4, 7, 9)
- **Five-Dimensional Growth Tracking**: Independent Thinking, Critical Evaluation, Reasoning Depth, Originality, and Self-Awareness -- scored consistently across all exercises to reveal growth patterns
- **Cumulative Portfolio**: Every exercise adds to a documented record that no one can fake because growth is visible across dozens of data points

### Critical Patterns
- Forward Map: trace where each chapter's skill returns before starting, so you understand why each chapter matters
- Score Tracking Table: record five scores after every exercise to see trajectory over 40 data points
- Cross-chapter links: later exercises reference earlier skills by name via "Building On" callouts

### Common Mistakes
- Treating chapters as independent and skipping ones that seem less relevant -- later chapters assume you have the named skills from earlier ones
- Focusing on individual scores rather than trajectories -- any single score may be noisy, but 40-exercise trends are meaningful
- Ignoring the forward map as decorative -- it is a functional dependency graph and a promise that every skill returns
