# Instructor Guide

> _Calibrate the instrument; do not change what it measures._

The AI check prompts in Part 0 are designed for the current generation of AI tools. As AI capabilities evolve, what counts as a rigorous evaluation today may need adjustment. This section provides a maintenance protocol to keep the assessment system accurate over time while preserving the five permanent Thinking Score Card dimensions.

## Teaching Aid

## What This Covers

- A five-step Semester Calibration Protocol for maintaining AI scoring accuracy
- Score distribution benchmarks (healthy vs. too lenient vs. too harsh)
- Prompt spot-testing methodology using archived student deliverables
- Feedback Challenge review patterns and what they reveal about prompt quality
- Model migration procedures when major AI versions release
- Scenario refresh guidelines for keeping exercises relevant
