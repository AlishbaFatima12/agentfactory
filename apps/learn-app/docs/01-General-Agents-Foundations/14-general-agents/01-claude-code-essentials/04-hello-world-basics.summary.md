# Lesson 4 Summary: Hello World & CLI Mastery

## Core Concept

Claude Code is not a chatbot; it's a **terminal-based agentic environment**. Mastering the interface (permissions, slash commands, and cost awareness) is the prerequisite for safe and effective development.

## Key Takeaways

- **The Permission Loop**: Claude cannot act without your approval for writes and command execution. Reading files does not require approval since it is a read-only operation.
- **Slash Commands**: Use `/help`, `/clear`, `/compact`, and `/cost` to control the environment.
- **Voice Input**: Type `/voice` to enable push-to-talk voice dictation (hold Space to speak). Useful for accessibility or longer instructions.
- **Output Styles**: Use `/config` to switch between output modes. **Learning** mode explains decisions and marks `TODO(human)` sections for you to complete, building real understanding.
- **The Cost Pill**: Always monitor session cost (top right) to maintain token hygiene.
- **Steering**: You don't just say "yes/no"; you can guide Claude ("No, edit this file instead").
