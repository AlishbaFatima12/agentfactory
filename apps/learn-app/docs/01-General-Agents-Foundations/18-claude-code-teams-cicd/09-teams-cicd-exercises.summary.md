This lesson provides 15 exercises across 7 modules that develop three core skills: **configuration engineering** (building CLAUDE.md hierarchies and path-scoped rules that scope correctly), **pipeline design** (automating Claude Code in CI/CD with structured output and duplicate avoidance), and **review architecture** (designing multi-pass workflows with session isolation that catch what single passes miss). Every exercise follows the Configuration Engineering Framework: Identify Scope, Choose Mechanism, Implement, Verify, Test Boundaries, and Document. Exercises pair build/apply tasks with debug/measure tasks, because creating configurations and diagnosing broken ones are equally essential skills.

The seven modules progress through the chapter's lessons: Module 1 (Configuration Architecture) covers CLAUDE.md hierarchies and path-scoped rules. Module 2 (Skills and Execution Strategy) covers custom skills with frontmatter and plan mode selection. Module 3 (Iterative Refinement) covers I/O examples, test-driven iteration, and the interview pattern. Module 4 (CI/CD Pipeline) covers the -p flag, structured JSON output, and duplicate avoidance. Module 5 (Review Architecture) covers multi-pass review scripts and self-review versus independent review. Module 6 (Session Mastery) covers named sessions, fork, inform, and compact across multi-day investigations. Module 7 (Integration Capstones) combines all modules into three projects: building complete team infrastructure, designing a production CI pipeline within a cost budget, and auditing your own Claude Code setup.

Self-assessment uses a 5-criteria rubric scoring configuration accuracy, tool selection, diagnostic skill, pipeline quality, and review design on a 1-4 scale. Module exercises target 12/20 or higher; capstones target 15/20, reflecting the integration difficulty. Students who score below target should revisit the corresponding lesson and reflection questions before proceeding to the next lesson: the Chapter 18 Quiz, which tests mastery of all configuration, CI/CD, and review concepts for the certification exam.
