# Lesson 5 Summary: The Assumption Stack

## What You Learned

You learned that every new venture is a portfolio of unproven assumptions , and that making those assumptions explicit before committing resources is the core discipline of the Lean Startup methodology. You built a structured assumption map using five categories (Customer, Problem, Solution, Business Model, Technical) and scored each assumption using the three-tier risk framework: TIER 1 (Existential, pivot required if wrong), TIER 2 (Serious, product changes significantly), and TIER 3 (Important, optimisation required). You assigned evidence quality (ASSUMED/ANECDOTAL/VALIDATED) to each assumption and designed minimum viable tests using the MVT hierarchy (Conversation → Landing Page → Concierge → Wizard of Oz → Functional MVP). You then sequenced the tests in a 4-week validation plan that prioritises TIER 1 assumptions first, at the lowest cost.

## Key Takeaways

- **Assumptions kill ventures more often than bad execution.** The most common cause of startup failure is building something customers do not want or will not pay for, both assumption failures, not execution failures.
- **VALIDATED means behaviour, not enthusiasm.** Payment or sustained usage is VALIDATED. Stated intent is ANECDOTAL. The evidence quality score makes this distinction visible on every assumption.
- **The cheapest test is always a conversation.** Most TIER 1 assumptions can be tested at MVT Level 1 (30 minutes, $0). Most teams build instead. This is how months of development produce learnings that a single afternoon of conversations would have revealed.
- **15 assumptions is not enough.** A complete assumption map targets 20-30 assumptions. Fewer than 15 means the team is missing business model or customer assumptions and focusing only on the comfortable product ones.
- **The test priority is: TIER 1 first, cheapest first.** Week 1-2 tests should cost nothing; they should be conversations that validate pricing, authority, and problem severity before a single line of code is written.
