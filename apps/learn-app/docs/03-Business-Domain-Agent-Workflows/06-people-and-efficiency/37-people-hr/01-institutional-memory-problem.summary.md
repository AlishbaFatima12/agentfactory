# The Institutional Memory Problem: Summary

## Key Concepts

- **Explicit knowledge**: Written information that exists in documents, theoretically findable, but often scattered and inaccessible in practice
- **Tacit knowledge**: Unwritten understandings that govern how things actually work, held in people's heads, lost when they leave
- **Information routing**: The HR function of answering questions that have written answers: the category that consumes the most HR time for the least value
- **Process execution**: The HR function of producing repetitive administrative documents, offer letters, JDs, onboarding plans, reference letters
- **Institutional knowledge capture**: The HR function of turning tacit knowledge into explicit documentation before it is lost
- **Three-function framework**: The lens for classifying any HR activity, information routing, process execution, or knowledge capture

## Skills Practised

- No plugin commands in this lesson, pure conceptual framing
- Knowledge classification: labelling any HR activity as explicit vs tacit, and assigning it to one of the three functions
- Diagnostic exercise: mapping an organisation's recurring HR questions to the explicit/tacit and three-function framework

## Key Takeaway

HR teams consumed by information routing, answering the same questions, writing the same documents, answering questions that written documentation already answers, have no capacity for the work that genuinely differentiates an organisation's talent strategy. The goal of an AI-native HR operation is not to replace HR professionals but to free them from the 60% so they can do the 40% better.
