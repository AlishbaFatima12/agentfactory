# Offer Letters & Employment Documents: Summary

## Key Concepts

- **Five Employment Document Types**: Offer letter, promotion letter, salary change notification, contract amendment, flexible working agreement, all follow the /draft-offer workflow
- **Jurisdiction-Specific Additions**: UK right-to-work check + P45; Pakistan EOBI contributions; UAE Labour Law probation limits, must be verified by HR reviewer
- **Three Reference Letter Types**: Factual (default, safest), Professional (requires written consent + HR sign-off), Employment Verification (for mortgage/visa applications only)
- **Two-Direction Legal Risk**: Defamation (false negative) and misrepresentation (falsely positive), both create liability. Factual references eliminate both risks.
- **REVIEW BEFORE SENDING**: Mandatory output from both skills. The AI draft is complete but must be reviewed against the verification checklist before sending. Never send a document containing the warning.

## Skills Practised

- `/draft-offer` (official human-resources plugin): Generates complete employment documents with jurisdiction-specific content and mandatory HR review flag
- `/reference` (custom hr-operations plugin): Generates factual, professional, or employment verification reference letters with mandatory HR review flag

## Key Takeaway

The HRBP's role in employment documentation shifts from writer to reviewer: the skill handles the drafting; the HR professional handles the verification. This is not a loss of control; it is a reallocation of effort from repetitive structure to judgment-intensive checking.
