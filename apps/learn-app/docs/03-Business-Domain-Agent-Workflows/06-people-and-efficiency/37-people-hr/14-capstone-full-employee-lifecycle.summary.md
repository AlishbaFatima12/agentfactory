# Capstone — The Full Employee Lifecycle — Summary

## Key Concepts

- **Lifecycle orchestration**: Selecting the correct skill for each stage of the employee lifecycle, sequencing them so each output informs the next, and applying human judgment at each handoff — not just using tools in isolation.
- **Six lifecycle stages**: HIRE (/jd, /interview-prep, /comp-analysis, /draft-offer), ONBOARD (/onboarding + onboarding-orchestrator), DEVELOP (/performance-review, /comp-analysis), RETAIN/PROMOTE (/match, /org-planning), OFFBOARD (/offboard, /knowledge + offboarding-knowledge-agent), CONTINUOUS (/people-report, /recruiting-pipeline + all four agents).
- **Sensitivity across the lifecycle**: ROUTINE documents (JD, interview plan, onboarding plan, org models) vs CONFIDENTIAL documents (offer letters, comp analysis, performance reviews, talent assessments, offboarding plans, knowledge capture guides).
- **hr.local.md as configuration**: Gaps in skill outputs point to missing hr.local.md entries — jurisdiction-specific notice periods, statutory rates, escalation contacts. The capstone reflection is where these gaps become visible.
- **AI as multiplier, not replacement**: The lifecycle sprint demonstrates what the AI contributes (structure, first drafts, benchmarking, systematic frameworks) and what only humans can contribute (ratings, specific evidence, career conversations, judgment about what matters).

## Skills Practised

All 14 skills and 4 agents from L03–L13, orchestrated across six lifecycle stages.

## Key Takeaway

An AI-native HR operation is not a collection of tools used occasionally — it is a coordinated stack where each skill and agent handles the right part of the lifecycle, continuously, with human judgment applied at the moments that require it. The lifecycle sprint is the proof of concept: when you run it, you are operating that stack.
