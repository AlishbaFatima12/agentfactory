# Quick Reference & Central Insights: Summary

## Key Concepts

- **Central insight**: Explicit knowledge → findable without asking. Tacit knowledge → captured before it leaves. HR professionals → freed for the 40% only humans can do
- **14 commands total**: 9 official (Anthropic) + 5 custom (Panaversity), zero overlap
- **4 persistent agents**: knowledge-base-agent (always-on), onboarding-orchestrator (HRIS trigger), policy-maintenance-agent (monthly), offboarding-knowledge-agent (resignation trigger)
- **Three sensitivity labels**: ROUTINE (standard), CONFIDENTIAL (personal data), SENSITIVE PERSONAL DATA (never auto-generate, escalate)
- **hr.local.md**: 8 sections, each controlling a specific category of plugin output

## Skills Practised

- Command lookup: identifying the correct command and plugin for any HR task
- Sensitivity classification: applying ROUTINE / CONFIDENTIAL / SENSITIVE PERSONAL DATA to any HR AI output
- Chapter contract review: answering the five questions that define chapter completion

## Key Takeaway

The reference tables in this lesson are externalised memory; they exist so you do not have to remember which of 14 commands handles which task. The classification framework (sensitivity labels, three functions, explicit vs tacit) is the thinking tool you carry forward. HR AI does not replace HR judgment ; it creates the capacity to exercise it properly.
