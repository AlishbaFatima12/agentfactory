### Core Concept

Task intelligence moves beyond recording tasks (lists) and structuring them (systems) to prioritising them against each other, surfacing risk, identifying delegation candidates, and finding the critical path. The brain dump pattern separates capture from classification, dump everything first, then let the skill structure and enrich with project context from work.local.md, then challenge the output with your own judgment.

### Key Mental Models

- **Brain Dump Pattern**: Capture (write everything, filter nothing) → Structure (skill extracts tasks, enriches with project context, identifies dependencies) → Challenge (you apply judgment the skill cannot, political sensitivity, relationship dynamics, unwritten priorities)
- **P1/P2/P3 Classification**: Five criteria applied in order (1) hard deadline, (2) blocking someone, (3) P1 project, (4) consequence of slipping one week, (5) real urgency vs habitual urgency. Maximum five P1 items, more than five means you are not prioritising
- **Task vs Project**: A task is completable in one session with a single output; a project has 3+ steps spanning multiple days and needs milestone planning, not just priority classification
- **Critical Path vs Priority**: Priority is about importance and urgency; critical path is about sequence and dependencies: a P2 task can be on the critical path if it blocks a P1 task later in the week

### Critical Patterns

- Separate capture from classification, filtering while dumping causes tasks to be forgotten
- Apply the five sorting criteria as a decision tree, not a checklist, work through them in order for each task
- The skill enriches tasks with context from work.local.md (project references, people, deadlines). This is task intelligence, not task management
- Challenge at least two classifications per brain dump: the dialogue with the skill develops your prioritisation judgment
- Identify 3-5 critical path items for the week: the sequence where a slip on one delays everything downstream

### Common Mistakes

- Classifying everything as P1 because it feels urgent, urgency is a feeling, priority is a judgment based on the five criteria
- Confusing the official productivity plugin's task CRUD with the custom plugin's task intelligence: one stores tasks (TASKS.md), the other thinks about them (brain dump, P1/P2/P3, critical path)
- Treating multi-day, multi-step items as tasks instead of projects; if it has more than 3 steps and spans more than one day, create a project entry in work.local.md
- Skipping the challenge step, accepting the skill's classification without applying your own context misses the point of the human-AI collaboration
