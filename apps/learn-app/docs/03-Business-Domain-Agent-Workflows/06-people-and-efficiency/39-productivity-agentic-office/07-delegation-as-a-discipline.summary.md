### Core Concept
A delegation is only as good as its brief. A vague delegation, "can you handle the analytics thing?", generates more work than doing the task yourself, because every missing element in the brief becomes a follow-up question the delegatee must ask. A complete brief gives the delegatee everything they need to succeed without returning for clarification.

### Key Mental Models
- **Brief completeness → rework prevention**: Every item missing from the seven-item checklist is a follow-up question. Map the question back to the checklist item to identify what the brief lacked. Write the brief; save the conversation.
- **Calibration changes the wrapper, not the task**: The delegation skill loads the delegatee's person entry from Layer 2 and calibrates the handoff message, channel, tone, lead time acknowledgement, scope specificity. The task is identical; the message is different because the person is different.
- **Follow-up as early warning**: The confirmation window and check-in cadence are not micromanagement; they are early warning. A delegation without a confirmation window may silently fail. A 24-hour confirmation check catches misunderstandings before they compound.

### Critical Patterns
- Apply the seven-item checklist before any delegation: specific deliverable, named person, firm deadline, context (purpose + audience), format specified, delegatee's preferred style, follow-up mechanism
- Run `/agentic-office:delegation` to produce a structured record including the calibrated handoff message loaded from work.local.md person entries
- Set a confirmation window (EOD for same-week tasks; 48 hours for longer ones) and define check-in cadence based on task duration
- Log every delegation in work.local.md with status lifecycle: PENDING CONFIRMATION → IN PROGRESS → COMPLETE / OVERDUE

### Common Mistakes
- Using "ASAP" as a deadline ; it produces the lowest-priority work on the delegatee's list; always use a specific date and time
- Delegating to "the team": one person owns the delivery; others may contribute, but accountability requires a named individual
- Closing a delegation as complete when it was sent rather than when the deliverable was received and verified
