### Core Concept

The capstone exercise wires every component built across Lessons 3–13 into a single, integrated system. Output quality from the three smoke test commands directly diagnoses `work.local.md` completeness — each C-grade output is a specific instruction about which memory section to improve.

### Key Mental Models

- **A/B/C Smoke Test Grading**: A = forward directly; B = minor edit needed; C = significant gaps. This is the diagnostic framework for evaluating any AI output, not just in the agentic office — it converts vague "not quite right" reactions into actionable improvement targets.
- **Outdated Context Is Worse Than No Context**: A confidently wrong output — one that presents stale information as current — is more dangerous than an empty output. The maintenance cadence is the commitment that prevents context decay from producing misinformation.
- **Four-Frequency Cadence**: Daily (automatic agent tasks, your role is confirm and act); weekly (20–30 min to review Memory Keeper proposals and delegation audit); monthly (terminology and people audit); quarterly (restructure priorities, thresholds, and org structure).

### Critical Patterns

- Seven-section `work.local.md` completeness checklist: personal, team (5+ people), projects (3–5 with codenames), organisational (15+ terms), digest config, dashboard config, agent integrations.
- Trigger events configuration maps external occurrences to agent actions (meeting ends → synthesis, new project → tracking, delegation → confirmation window).
- Escalation thresholds by item type: delegation unconfirmed (24 hrs), project status stale (7 days), compliance obligation (3 days before due), vendor renewal (90 days out).
- Integration smoke test sequence: `/agentic-office:progress-tracker` → `/agentic-office:digest` → `/agentic-office:workplace-search "what is at risk?"`.
- Most C-grades trace to: Layer 3 (projects incomplete), `chief_of_staff.feeds_from` (domain agents not listed), or digest/dashboard configuration gaps.

### Common Mistakes

- Treating the initial configuration as permanent: thresholds calibrated for one quarter may be wrong the next as pace of work changes.
- Grading a C-grade output as "the system is broken" — the system is correctly surfacing what `work.local.md` doesn't know.
