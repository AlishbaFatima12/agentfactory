### Core Concept

The capstone reveals whether the chapter's eight skills and five agents form a connected system or a collection of independent tools. The cross-phase dependency chain is the test: classification tiers must flow into assessment depth, assessment scores into risk thresholds, thresholds into agent configuration. A capstone that breaks at any dependency reveals a gap in the earlier work.

### Key Mental Models

- **Seven-Phase Dependency Chain**: Classification → Assessment → Reconciliation Rules → Risk Dashboard → Logistics and Spend Baseline → Agent Deployment → Executive Brief. Each phase calibrates the next — not a checklist, a system.
- **"Would Your CPO Act On This?"**: The quality standard for the final executive brief is not training adequacy — it is whether a real CPO would make a decision based on it
- **Own Data = Deployable Output**: Students who used real organisational data throughout the chapter produce a genuine deployment starting point, not a training artefact

### Critical Patterns

- Trace the dependency chain explicitly before starting Phase 3 — verify that classification tiers and assessment scores are consistent before configuring reconciliation rules against them
- Use Exercise outputs as calibration inputs: Exercise 1's classification register → Phases 1-2; Exercise 8's exit experience → Phase 4 alert threshold design
- Generate the executive brief last — it should be a natural synthesis of the phase outputs, not a summary written from memory
- The capstone deliverable is specific: classification register, vendor assessments, reconciliation rule configuration, risk dashboard, logistics and spend baseline, five deployed agents, first CPO/COO brief

### Common Mistakes

- Treating the seven phases as independent steps — the whole point is that each phase's output is the next phase's input
- Producing a brief formatted for a training exercise rather than CPO consumption — the evaluation question is real, not rhetorical
- Starting the capstone with new or placeholder data — the chapter exercises built the inputs; use them

### Connections

- **Builds on**: All lessons in Chapter 35 — the capstone integrates every skill and agent introduced across 13 lessons
- **Leads to**: Real deployment — the classification register, agent configurations, and executive brief format are the artefacts a procurement team would use in production
