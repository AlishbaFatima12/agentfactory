## Summary: Roadmap Planning & Communication

- **Key concept**: A roadmap is a communication tool, not a project plan. The same initiative requires three different registers: engineering needs sprint-level commitments, executives need commercial outcomes, and customers need benefit language. Now/Next/Later avoids the false date precision that turns roadmaps into contracts.
- **Command(s) used**: `/roadmap-update` (official `product-management` plugin)
- **Artifact produced**: InsightFlow Q3 roadmap in Now/Next/Later format — with Workflow Builder as the primary Now theme, cross-team dependencies mapped, capacity validated against 70/20/10 rule, and three audience-calibrated versions (engineering, executive, customer-facing)
- **Quality criteria**: All dependencies named with owners and need-by dates; capacity allocation verified (no more than 70% to planned features); customer version uses benefit language with no specific dates; roadmap change communications use the five-step framework
