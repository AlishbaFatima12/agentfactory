# Chapter 30: The PRIMM-AI Framework

> *"The PRIMM approach recognises that starting with existing code and being able to explain what it does gives novice programmers the confidence to write their own programs."*
> — Sentance, Waite, and Kallia (2019)

## What You Will Learn

Before you write a single line of Python, you need to understand *how* you will learn. This chapter introduces the pedagogical framework that governs all programming instruction in this book: **PRIMM-AI** — Predict, Run, Investigate, Modify, Make *with AI*. Built on research-validated principles from computing education, PRIMM-AI teaches you to read and understand code before you ever try to write it — and integrates AI coding assistants as learning partners at every stage.

## Learning Outcomes

By the end of this chapter, you will be able to:

- Explain the five stages of PRIMM and why they are sequenced in that order
- Describe how AI coding assistants integrate into each PRIMM stage
- State the five PRIMM-AI rules and explain why each matters in the AI era
- Recognize the difference between generating code and understanding code
- Articulate how PRIMM-AI connects to the professional Spec-Generate-Review-Refine-Ship workflow

## What This Chapter Is Not

This chapter teaches **no Python**. No tools are installed. No code is written. It is a conceptual chapter that establishes the learning contract: here is how every lesson works, and here is why this approach produces better developers than the old "type from scratch" model.

The next chapter (Chapter 31: Ten Axioms) teaches what professional practice looks like. This chapter teaches how you will internalize those practices. Together they form the complete system — the developer's comprehension and the software's correctness.
