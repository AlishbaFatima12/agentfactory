### Core Concept
The variable shift tests whether you understand your cascade map deeply enough to adapt it when conditions change. A student who derived their map from understood mechanisms can revise it; a student who copied AI's output has to start over because they never understood why the connections existed.

### Key Mental Models
- **Static vs. Dynamic Analysis**: A static map is a snapshot; dynamic systems thinking understands the mechanisms, enabling adaptation when variables change
- **Change Propagation**: In interconnected systems, changing one variable propagates across all domains; the effect is never contained to just one category
- **Revision as Assessment**: The revision process itself reveals understanding; which connections you keep, remove, or modify shows whether you understood the original mechanisms

### Critical Patterns
- Revise the existing map rather than starting fresh; show what changed and why
- Use visual marking: green (new connections), red/strikethrough (removed), yellow (modified)
- Write a change log with one-sentence explanations for each modification
- Compare your adaptation against AI's re-analysis to identify different strategies

### Common Mistakes
- Trying to start from scratch instead of revising; this hides whether you understood the original analysis
- Making only surface-level changes (swapping labels) instead of tracing how the variable shift cascades through the system
- Assuming the variable shift affects only one domain; interconnected systems propagate changes across all domains
