# James & Emma Narrative Checklist

Run this checklist before writing or reviewing any chapter.

---

## JAMES & EMMA NARRATIVE CHECKLIST

### Phase Check
- [ ] Checked narrative density target for this Part (see character-profiles.md)
- [ ] Narrative mode matches chapter type (Dialogue-Driven / Failure-Hook / Operational / Bookend)

### James Agency
- [ ] James pushes back or resists at least once per lesson
- [ ] James reaches at least one conclusion independently (not told by Emma)
- [ ] James proposes at least one alternative approach (even if wrong)
- [ ] James paraphrases in his own words (with analogies from his background)
- [ ] James never regresses a skill previously learned (checked competence list)

### Emma Humanity
- [ ] Emma has at least one fallibility moment per chapter (uncertainty / past mistake / learns from James)
- [ ] No Emma monologue exceeds 3-4 sentences without James reacting
- [ ] Emma asks questions more than she gives answers (count the ratio)
- [ ] Emma uses at least one Socratic question type beyond simple clarification

### Dialogue Quality
- [ ] James and Emma sound different (cover tags -- can you tell who's speaking?)
- [ ] At least one disagreement lasts 3+ exchanges before resolution
- [ ] James uses "non-tech analogy" speech pattern at least once
- [ ] No "As You Know, Bob" moments (characters explaining what both already know)

### Emotional Design
- [ ] If this is a dropout-risk chapter, strongest character beat is placed here
- [ ] Character emotional state matches expected reader emotional state

### Concept Independence
- [ ] Every concept discussed has a standalone name (not dependent on character context)
- [ ] Technical content is findable without reading narrative sections

---

## How to Use This Checklist

### For WRITING new chapters:
1. Run the **Phase Check** section BEFORE writing any narrative
2. Write the chapter
3. Run ALL sections after writing to verify compliance
4. Fix any violations before considering the chapter complete

### For AUDITING existing chapters:
1. Read all lessons in the chapter
2. Run each checklist item, noting file:line for violations
3. Count quantitative items (monologue lengths, pushback exchanges, fallibility moments)
4. Report violations in the audit report format (see SKILL.md Output Standard)

### Counting Guidelines

| Item | How to Count |
|------|-------------|
| Pushback exchanges | James explicitly disagrees, questions, or proposes alternative |
| Independent conclusions | James states a correct (or partially correct) insight without being told |
| Emma monologue length | Count consecutive Emma sentences with no James reaction between them |
| Socratic question types | Clarification, assumptions, evidence, viewpoints, implications, meta-questions |
| Disagreement exchanges | Count back-and-forth turns where James and Emma hold different positions |

### Six Socratic Question Types (Reference)

Use variety -- don't default to only clarification questions:

1. **Clarification**: "What do you mean by...?"
2. **Probing assumptions**: "What are you assuming here?"
3. **Probing evidence**: "How do you know that's true?"
4. **Exploring viewpoints**: "What would someone who disagrees say?"
5. **Probing implications**: "If that's true, what follows?"
6. **Meta-questions**: "Why is this question important?"
