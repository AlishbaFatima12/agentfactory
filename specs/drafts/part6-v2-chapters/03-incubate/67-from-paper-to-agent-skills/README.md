# Chapter 67: From Paper to Agent Skills

## Overview

You have a validated concept paper and confirmed domain mastery. Now you convert that domain knowledge into agent intelligence. This chapter teaches the transformation method: how to systematically extract decision logic from your concept paper and encode it as SKILL.md files that agents can execute.

By the end of this chapter, you will have four agent skills for HireFlow's four Digital FTEs: Job Spec Writer, Resume Screener, Interview Question Generator, and Candidate Summarizer. These skills are the foundation of Phase 2 (Incubate) and feed directly into simulation (Chapter 68) and MCP integration (Chapters 69-71).

## What You Will Learn

- Why domain knowledge and agent intelligence are different things
- The Extract-Structure-Encode transformation method for converting concept paper sections into skill specifications
- SKILL.md anatomy: Persona, Questions, and Principles for execution skills
- How to write skills with graduated independence (from guided to fully independent)
- How inter-FTE data contracts create consistency across a skill ecosystem

## Key Terms Introduced

| Term                        | Definition                                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Transformation Method**   | The systematic process of converting concept paper knowledge into agent skill specifications: Extract, Structure, Encode |
| **Domain Requirement**      | A specific capability, decision, or edge case identified in the concept paper that the agent must handle                 |
| **Decision Logic**          | A structured "When X, do Y because Z" statement that encodes domain judgment                                             |
| **Execution Skill**         | A skill that orchestrates autonomous behavior (writing, scoring, generating), not just advice                            |
| **Inter-FTE Data Contract** | The agreed format and content of data passed between agent skills in a factory pipeline                                  |
| **Scoring Rubric**          | Specific, weighted criteria that make agent evaluation consistent and auditable                                          |
| **Skill Specificity**       | The degree to which a skill encodes concrete decision logic versus vague instructions                                    |
| **Graduated Independence**  | A teaching pattern where each successive skill is written with less scaffolding                                          |
