### Core Concept

The concept paper is not the endpoint of Phase 1: it feeds the Domain Mastery Gate (Ch 66), which feeds Agent Skill extraction (Ch 67). The concept paper is a validated document; domain mastery is the corresponding knowledge held in the builder's head. Both are required before Phase 2 begins. The concept paper also serves as the reference artifact for every subsequent chapter in Part 6.

### Key Mental Models

- **Paper vs. Internalized Knowledge**: A surgeon reads the procedure manual (concept paper). A surgeon who can perform the procedure without consulting the manual has domain mastery. Writing the concept paper does not guarantee the builder has internalized it.
- **The Four-Chapter Build Chain**: Blueprint (Ch 64) feeds Concept Paper (Ch 65), which feeds Domain Mastery Gate (Ch 66), which unlocks Agent Skills (Ch 67). Each chapter is a prerequisite for the next. The gate between Ch 65 and Ch 67 tests whether the builder crossed from understanding the document to owning the domain.
- **Concept Paper as Persistent Reference**: The concept paper is referenced in Ch 67 (skill extraction), Ch 76 (database schemas derived from data contracts), Ch 78-81 (each FTE's behavior checked against the paper), and Ch 90 (capstone verification). It is the seed document for the entire Part 6 build.

### Critical Patterns

- A builder who can write "evaluate candidates fairly" but not "distinguish spectrum qualification matching from binary matching for senior technical roles" has the document, not the mastery. The gate catches this before the builder writes skills.
- Vague agent skills produce vague agent behavior. The concept paper's specificity is only useful if the skill writer has internalized the specificity, not just referenced it.
- Phase 1 (Explore) ends at the Domain Mastery Gate, not at the concept paper. Phase 2 (Incubate) begins with intelligence: skills and protocols that define how each FTE reasons. Code (Phase 3) comes after intelligence is established.

### Common Mistakes

- Treating the crystallized concept paper as permission to start writing code (the Domain Mastery Gate comes first; passing the gate is the permission)
- Believing the concept paper and domain mastery are the same thing (the paper is an artifact; mastery is a capability)
- Underestimating the concept paper's downstream role (it is not a Phase 1 deliverable to be filed away; it is the reference document for all of Part 6)
